# Тренажёр немецкого — числа и слова

Локальный сайт с тренажёром немецких числительных и слов, плюс админ-панель
для добавления своих слов (хранятся в файле `data/db.json`).

## Запуск

Нужен установленный Node.js (скачать: https://nodejs.org, версия 18 или новее).

1. Открой терминал в этой папке.
2. Установи зависимости (один раз):
   ```
   npm install
   ```
3. Запусти сервер:
   ```
   npm start
   ```
4. Открой в браузере:
   - Тренажёр: http://localhost:3000
   - Админ-панель: http://localhost:3000/admin.html

Сервер работает, пока открыт терминал. Чтобы остановить — Ctrl+C.

## Пароль админ-панели

По умолчанию пароль: `changeme123`.
Поменяй его в файле `data/config.json` (поле `adminPassword`) и перезапусти сервер.
Без правильного пароля страница `/admin.html` и любые изменения слов (API)
недоступны.

## Тёмная / светлая тема

Кнопка-кружок в правом верхнем углу переключает тему. Выбор запоминается
в браузере (localStorage), при следующем открытии применится автоматически.

## Несколько вариантов ответа

В переводе можно указать несколько допустимых вариантов через `/`,
например `кот / кошка` или `собака / пёс`. Любой из них засчитается
как правильный ответ. Работает и для немецкого, и для русского поля.

## Без повторов подряд

Одно и то же слово (или число) не выпадет два раза подряд — следующий
вопрос всегда берётся из оставшихся вариантов в выбранных категориях/диапазонах.

## Параметры — теперь в отдельном окне

Чтобы не загромождать экран, диапазоны/категории, направление и
дополнительные настройки убраны с главного экрана и открываются кнопкой
"⚙ Параметры" над карточкой тренажёра. В этом окне также находятся:

- **Показывать кнопки умляутов (ä ö ü ß)** — если снять галочку, ряд кнопок
  над полем ответа скрывается на обеих вкладках. Настройка общая для чисел
  и слов и запоминается в браузере.
- **Умный подбор** — отдельная галочка для чисел и для слов. Когда включена,
  вопросы, в которых вы чаще ошибались, начинают попадаться заметно чаще
  (но не выпадают ими одними — остальные варианты тоже продолжают
  встречаться). Статистика ошибок хранится в этом браузере (в
  `localStorage`, как и текущий счёт с темой оформления) — при чистке данных
  сайта в браузере она сбросится.

## Админ-панель: категория за раз

Вместо того чтобы разворачивать сразу все категории на странице (из-за чего
при большом числе слов было неудобно скроллить и редактировать), в
админ-панели теперь есть выпадающий список "Категория для редактирования".
Выбираешь нужную — показывается только она, с полем поиска по словам внутри
категории и таблицей с собственной прокруткой, которая не растягивает всю
страницу.

## Как добавлять слова

Зайди на страницу админки (ссылка внизу главной страницы или напрямую
`/admin.html`). Там можно:
- создавать категории слов (например, "Глаголы A1", "Еда", "Профессии");
- выбрать категорию в списке и добавлять в неё слова (немецкое слово + перевод);
- искать, редактировать и удалять слова внутри выбранной категории;
- переименовывать и удалять саму категорию.

Все данные сохраняются в файл `data/db.json` — его можно бэкапить,
редактировать вручную или перенести на другой компьютер.

## Как это устроено

- `server.js` — сервер на Express, отдаёт статические страницы и REST API
  (`/api/categories`, `/api/categories/:id/words`, `/api/words/:id`).
- `data/db.json` — простая база в виде JSON-файла.
- `public/` — фронтенд: `index.html` (тренажёр с вкладками "Числа" и "Слова"),
  `admin.html` (админка), плюс JS/CSS.

Числа генерируются на лету (0–12, 12–19, 20–90 с обоими направлениями:
цифра→слово и слово→цифра). Слова работают так же, только берутся из базы
и группируются по категориям, которые можно включать/выключать галочками.
